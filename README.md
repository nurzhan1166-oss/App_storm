## 📌 О проекте

**App_storm** — это мобильное приложение, разработанное в процессе обучения в **ALT University**. Проект ориентирован на высокую производительность, адаптивный пользовательский интерфейс и кроссплатформенную совместимость (Android / iOS).

---

## 🛠 Технологический стек

В разработке проекта использовались современные технологии и инструменты:
* **Фреймворк:** [React Native](https://reactnative.dev/) (с поддержкой Expo)
* **Язык программирования:** [TypeScript](https://www.typescriptlang.org/) / JavaScript
* **Среда разработки:** Visual Studio Code
* **Эмуляция и тестирование:** Android Studio (Android Emulator) / Expo Go
* **Управление пакетами:** npm

Инструкция по установке и запуску
Для того чтобы развернуть проект локально на вашем компьютере и запустить его в эмуляторе или на реальном устройстве, выполните следующие шаги:

1. Системные требования
Убедитесь, что на вашем компьютере установлены:

Node.js (рекомендуемая версия 18.x или выше)

Git

Android Studio (с настроенным Android Emulator) или приложение Expo Go на мобильном устройстве.

2. Клонирование репозитория
Откройте терминал и выполните команду для клонирования проекта:

Bash
git clone [https://github.com/nurzhan1166-oss/App_storm.git](https://github.com/nurzhan1166-oss/App_storm.git)
3. Переход в папку проекта
Bash
cd App_storm
4. Установка зависимостей
Установите все необходимые пакеты и модули:

Bash
npm install
5. Запуск приложения
Запустите сервер разработки Expo:

Bash
npx expo start
После запуска сервера в терминале выберите вариант тестирования:

Нажмите клавишу a, чтобы открыть приложение в Android Emulator (требуется запущенный Android Studio).

Отсканируйте QR-код с помощью камеры телефона (на iOS) или приложения Expo Go (на Android) для запуска на физическом устройстве.
